# Uni Recomend — фронтенд

React (Vite + TypeScript) для регистрации/входа, прохождения опросника и просмотра рекомендаций вузов.

## Запуск

1. Установить зависимости:
   ```bash
   cd frontend && npm install
   ```

2. Запустить бэкенд (из корня проекта):
   ```bash
   make run-dev
   ```
   API должен быть доступен на `http://localhost:8000`.

3. Запустить фронтенд:
   ```bash
   npm run dev
   ```
   Откроется `http://localhost:8080`. Запросы к `/api` проксируются на бэкенд.

## Маршруты

- `/login` — вход
- `/register` — регистрация
- `/survey` — опрос (требуется авторизация)
- `/results` — результаты (последние рекомендации вузов)

## Сборка

```bash
npm run build
```
Статика в `dist/`. Для продакшена нужно раздавать её и проксировать `/api` на бэкенд.
